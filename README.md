# The World in One Day — 17 November 2026

A single 1024×1024 front page summing up Tuesday 17 November 2026: 23 verified stories
across six continents, three illustrated leads, a numbered world map and the day's
numbers. Built for the make.fun bounty **“Sum up 17 November's world news in one image.”**

## Run

```
python3 main.py          # writes entry.png to /output (or $MAKEFUN_OUTPUT_DIR)
```

No network, no dependencies, standard library only. The program is deterministic: both
runs write the same bytes.

## Sources

Reuters · AP · AFP · BBC · Al Jazeera · UN · WHO · PAHO · Xinhua. Every item happened or
